# GameResume - Five Trials of Grok

An interactive, gamified resume and cover letter experience. This project presents a creative take on traditional job applications through an immersive HTML5 interactive experience.

## Overview

**Five Trials of Grok** is a game-based portfolio piece featuring:
- Interactive gameplay elements
- Cyberpunk/neon aesthetic with animated visuals
- Canvas-based graphics
- Responsive design
- Modular trial-based content system

## Features

- **Animated Canvas Graphics**: Dynamic visual effects and animations
- **Interactive Trials**: Game-like challenges and content exploration
- **Custom Styling**: Futuristic design with neon color scheme (blue, gold, cyan, red)
- **Responsive Layout**: Optimized for various screen sizes
- **Typography**: Uses Orbitron and Share Tech Mono fonts for a tech aesthetic

## Technologies

- HTML5
- CSS3 (with animations and transitions)
- JavaScript
- Canvas API

## Getting Started

Simply open `Resume and coverletter.html` in a web browser to view the interactive experience.
